HOME with YURA Ver.0.01

GitHub Pagesで使う場合:
1. 新しいリポジトリを作る（例 home-with-yura）
2. このZIPを展開して中身を全部アップロード
3. Settings → Pages
4. Deploy from a branch / main / /(root) → Save
5. 公開URLをSafariで開く
6. 共有 → ホーム画面に追加

データ保存:
localStorageを使用。バックアップJSONの書き出し/読み込み機能あり。

注意:
OpenAI APIキーはHTMLやJavaScriptに直接書かないでください。
